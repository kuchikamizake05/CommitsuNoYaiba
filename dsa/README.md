# Coding practice

Open the next problem in [the tracker](../tracker.md). Read Description and constraints; keep Editorial and Solutions closed during the attempt. Use Java initially and turn off AI completion.

## Starter order

1. [Contains Duplicate](https://leetcode.com/problems/contains-duplicate/): baseline for traversal, comparison, and membership.
2. [Two Sum](https://leetcode.com/problems/two-sum/): practise the difference between indices and values, and avoiding element reuse.
3. [Valid Anagram](https://leetcode.com/problems/valid-anagram/): practise counting and comparing information from strings.

These are our initial selections, not a claim that they belong to a particular official study plan. Do not expand the queue until you have reviewed these attempts.

When choosing subsequent problems, use your most recent gap. First pick another Easy in the same family; after a cold retry and a variation pass, introduce one new family. Future candidates: two pointers, stack, binary search, then traversal with a queue/recursion. Difficulty labels are guidance, not a time guarantee.

[LeetCode 75](https://leetcode.com/studyplan/leetcode-75/) is an official source for a broader interview problem list. Use it as a bank to select from after calibration, not a completion deadline. Avoid random daily questions as your main sequence.

## Save an attempt

Create a folder such as `contains-duplicate/` only when starting that problem. Keep:

- Your independently written `Solution.java` (or another selected language).
- `notes.md` with your approach, tests, complexity, and help used.
- Runnable tests if practising locally; otherwise record custom input, expected result, and observed result in the note.

LeetCode supplies the driver for its `Solution` class. To run locally, supply your own small test driver; do not expect a bare `Solution.java` to run as an application.

Keep dated attempts if useful, rather than replacing the first attempt with an AI-written answer. Link the folder from the tracker. Summarize the task in your own words and link its statement instead of copying full problem statements/editorials.
