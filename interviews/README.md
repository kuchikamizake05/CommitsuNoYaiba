# Interview practice

Practise communication from the first coding session. Explain inputs, a simple approach, why it works, time/memory costs, and test cases while writing code.

For a live-coding retry, start a blank editor and a 25-minute timer. Speak aloud, implement, test, and summarize any remaining flaw. A recording is optional and stays outside this public repo; store only factual review notes here.

For technical interviews, use the project deep-dive guide. For user/behavioural interviews, prepare short factual stories about a task, your responsibility, what you did, the outcome, and what you learned. Avoid identifying private team members or publishing sensitive incidents.

Use [the session template](session-template.md) for any exercise. Language and interview duration can be adapted later to a specific application.
