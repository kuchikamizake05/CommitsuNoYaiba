# Project deep dives

Use LedgerFlow, FinTrack, and Gatherly as material for explaining your own work. Keep the application code in its original repository.

Start with LedgerFlow:

1. Without reading code, explain a transfer from request to database and response.
2. Explain what should happen when the balance is insufficient or the same request is retried.
3. Inspect the actual implementation and tests. Record what you got wrong and the relevant source links.
4. Rebuild one small piece independently: input validation or a simplified transfer rule. Keep that learning exercise here, clearly labelled as a simplified version.

Create `ledgerflow/notes.md` when you start. Separate claims verified in source/tests from behaviour you merely expect. For interviews, distinguish what you implemented independently, what AI helped generate, and what you subsequently verified.
