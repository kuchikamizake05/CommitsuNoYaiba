> A personal coding dojo: learn, build, make mistakes, and understand the way forward.

Commitsu no Yaiba is my learning archive for software engineering. Here I practise coding fundamentals, explore backend development, solve algorithm problems, build small projects, and revisit what I learn along the way.

The goal is to grow into an independent developer: write code, test ideas, explain decisions, and return to the parts I haven't mastered yet. Not every attempt has to be perfect to be worth keeping.

## Inside the dojo

| Area | What lives here |
| --- | --- |
| [.NET dojo](dotnet-dojo/) | C#, .NET, backend exercises, and a mini project |
| [Fundamentals](fundamentals/) | Focused practice in core programming concepts |
| [DSA](dsa/) and [LeetCode](leetcode/) | Algorithms, data structures, and problem-solving practice |
| [Backend](backend/) | APIs, databases, authentication, and other backend concepts |
| [Design](design/) | Software design exercises |

Use the [practice guide](roadmap.md) for an existing interview-preparation cycle, and the [tracker](tracker.md) to record that cycle honestly. Other learning paths can grow alongside it at their own pace.

## How I learn

- Start with understanding the problem and trying things myself.
- Keep notes on what worked, what did not, and what I want to revisit.
- Use documentation and help thoughtfully, then practise explaining the solution independently.
- Keep examples synthetic and respect the confidentiality of work and course materials.
