# CommitsuNoYaiba

Repo belajar pribadi untuk mempersiapkan coding test, live coding, dan technical interview software engineering internship.

Di sini aku akan mencatat latihan, kesalahan, eksperimen, dan pemahaman yang dibangun sendiri—bukan sekadar mengumpulkan solusi yang sudah jadi.

## Fokus

- Problem solving, algoritma, dan struktur data.
- Coding sambil menjelaskan pendekatan dan menguji hasilnya.
- Fondasi backend: HTTP, SQL, transaksi database, dan penanganan kegagalan.
- Bedah proyek sendiri agar bisa menjelaskan alur serta keputusan teknisnya.

## Aturan belajar

1. Coba sendiri sebelum meminta bantuan AI.
2. Jika mentok, minta petunjuk terlebih dahulu, bukan kode lengkap.
3. Catat bantuan yang dipakai dan bagian yang belum dipahami.
4. Kerjakan ulang tanpa melihat solusi sebelum menganggap materi dikuasai.

Kurikulum dan struktur latihan akan disusun setelah mengevaluasi kemampuan awal.
