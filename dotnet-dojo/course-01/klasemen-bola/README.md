# OOP: classes and objects

A small C# exercise to explore classes, objects, constructors, properties, and methods. Created with AI assistance for guided study; completion and understanding are not yet recorded.

Course: [C# & ASP.NET MVC Fundamentals](https://rocketversity.com/course/view.php?id=66) — C# Introduction Object Oriented Programming.

Build with `dotnet build`. If Windows blocks the generated executable, run `dotnet bin/Debug/net8.0/01-oop.dll` after building. The example uses fictional learning data and does not reproduce company course material.
