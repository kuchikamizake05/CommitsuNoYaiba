# Fundamentals

Small language and debugging exercises, selected when an attempt exposes a gap.

Start with arrays, loops, methods, strings, and collection operations. Later add references, equality, exceptions, and simple class design when needed.

Use [Dev.java Learn](https://dev.java/learn/) for Java concepts and API documentation for syntax. Read only the section needed for the current exercise, then close it and write a fresh example.

Save one folder per exercise, such as `array-traversal/`: your code, a runnable test or checked examples, and a short note using [the template](../interviews/session-template.md). No exercise solutions are prefilled.

First gap exercise if the baseline is blocked: write a method that counts occurrences of a supplied integer in an array. Test one match, multiple matches, and no match; explain each loop variable.
